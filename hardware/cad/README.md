# Source CAD

Store editable enclosure and bracket models here. Prefer a format that preserves the
design history; include a neutral STEP export when the authoring tool supports it.

Each CAD release should document:

- Hardware revision and compatible device profile.
- Authoring application and version.
- Units and critical tolerances.
- Purchased-part models used as references and their licenses.
- Mapping from source bodies/components to files in [`../stl/`](../stl/).
- License for the original Muse Cam mechanical design.

Do not commit third-party vendor models unless their license permits redistribution.
